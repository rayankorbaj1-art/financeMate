# Data profile

This document records the checks produced by the starter-data profiling step.

## Required checks

- Total number of records
- Number of records per month
- Number of income and expense records
- Category counts
- Missing required values
- Duplicate IDs
- Invalid transaction types
- Invalid or non-positive amounts
- Invalid date formats

## Review outcome

Complete this document after the profiling script has been run. Any failed
check should be resolved before the data is imported into SQLite.
