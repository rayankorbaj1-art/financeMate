# Idea card

## Target user

A person who wants a straightforward way to understand their personal
spending during each month.

## User problem

Financial totals alone do not explain which purchases and categories caused
the spending.

## Main user flow

1. The user opens the dashboard.
2. The user selects a month.
3. The user reviews income, expenses, and the difference.
4. The user selects a spending category.
5. The user reviews the transactions behind that category total.
6. The user can search, filter, add, edit, or delete transactions.
